### What I'm building

**[Movie Rating Extension](https://github.com/F1x-hub/MovieListExtension)**<br>
Chrome extension for finding, rating and watching films and series. Kinopoisk and TMDB data, lists and reviews synced through Firebase, its own HLS player with frame previews on the timeline. A small C# app on the Windows side handles torrent sources; one setup file installs everything and it updates itself. Also has a [web version](https://github.com/F1x-hub/hostedMovieList) on Next.js ([demo](https://hosted-movie-list.vercel.app)) and a [Telegram bot](https://github.com/F1x-hub/Movie_Preview_Bot) for announcements.

**[SteamMini](https://github.com/F1x-hub/SteamMini)**<br>
Lightweight Steam client on Electron: achievements, card drop farming, wishlist prices compared across regions. The Steam API work runs in two small .NET processes.

**WebNovel** ([API](https://github.com/F1x-hub/WebNovelAPI) · [client](https://github.com/F1x-hub/webnovel-front))<br>
Site for publishing and reading web novels. ASP.NET Core 8, EF Core, SQL Server, Redis on the back, Angular on the front. Chapter editor, reading progress, rankings, coins for paid chapters, admin panel.
